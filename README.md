# 3-зертханалық жұмыс — Git тармақтары

## Мақсаты
Тармақтармен (main / develop / feature) жұмыс істеуді меңгеруге арналған оқу репозиторийі.

## Әзірлеуді баптау
1. `git clone <сілтеме>` орындап, жоба қалтасына өт
2. Авторды бапта: `git config user.name "..."` және `git config user.email "..."`
3. Жылдам алға жылжытуды өшір: `git config branch.main.mergeoptions "--no-ff"` және `git config branch.develop.mergeoptions "--no-ff"`
4. `develop` тармағынан `feature/<мүмкіндік-атауы>` тармақтарын құрып жұмыс істе
